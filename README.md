# Инструкция по установке проекта:
## 1. Установка БД:
1. Создать новую базу данных в PostreSQL.
2. Открыть меню над базой данных, нажать **Restore...**
3. В параметре **Filename** выбрать файл **web8_backup.sql**
## 2. Установка Backend:
1. Создать виртуальное окружение для проекта.
2. Прописать в консоле:
   > pip install fastapi bcrypt python-jose python-dotenv dotenv flake8 psycopg2
3. Заменить в файле **.env** данные о БД на свои.
4. Запуск осуществляется через команду:
   > python main.py
## 3. Установка Frontend:
1. Прописать в консоле:
   > npm install
2. Запуск осуществляется через команду:
   > npm start
